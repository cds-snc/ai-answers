# Managing multiple CanadaLogins

## On this page

- Using CanadaLogin for personal use and professional use
- Using multiple CanadaLogins to access role-based accounts

## Using CanadaLogin for personal and professional use

If you are accessing a service for personal use, we recommend you use a personal email to create your CanadaLogin.

If you are accessing a service on behalf of a business, we recommended using a business email to create your CanadaLogin.

## Using multiple CanadaLogins to access role-based accounts

You may want to set up multiple CanadaLogins to access different accounts within the same portal. This is usually done to sign in to accounts with different permissions or roles.

Each CanadaLogin must be associated to a unique email address. You can use different email addresses or choose to use aliases.

### Managing multiple CanadaLogins from the same email inbox

You can create multiple CanadaLogins with unique email addresses and still manage them from the same email inbox using aliases.

An alias is an alternate email address tied to an existing address. It uses the same inbox and settings.

You can set up aliases if your email service provider offers it. Popular email providers like Outlook and Google offer this feature.
