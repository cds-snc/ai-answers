# Qu’est-ce que la vérification en deux étapes?

La vérification en deux étapes est une méthode de connexion dans le cadre de laquelle il vous est demandé de vous authentifier de deux façons différentes pour confirmer votre identité. En plus de votre mot de passe (première étape), ConnexionCanada exige que vous configuriez au moins une autre méthode de connexion (deuxième étape) pour sécuriser votre compte.

Nous vous invitons à ajouter plusieurs « secondes étapes » à votre compte pour pouvoir choisir entre plusieurs options de vérification au moment de la vérification en deux étapes. De cette manière, si vous perdez accès à l’une de vos secondes étapes (comme votre téléphone), vous aurez une option de secours pour accéder à votre compte.

Si vous perdez toutes vos méthodes d’authentification et que vous perdez accès à votre compte, ConnexionCanada ne sera pas en mesure de vous accorder l’accès. Vous devrez créer un nouveau compte.

Vous trouverez plus de renseignements sur les différentes méthodes de vérification en deux étapes dans les sections suivantes :

- Clés d’accès
- Vérification par téléphone

## Clés d’accès

### Que sont les clés d’accès?

Les clés d’accès sont des clés numériques chiffrées que vous créez à l’aide de votre empreinte digitale, de votre visage ou de votre méthode de déverrouillage d’écran. 

### Pourquoi devrais-je utiliser une clé d’accès?

Les mots de passe sont difficiles à retenir et faciles à voler. En revanche, pas besoin de retenir les clés d’accès : elles sont connectées à votre appareil et vous y accédez à l’aide de votre empreinte digitale, de votre visage ou de la méthode de déverrouillage de votre écran.

Les clés d’accès sont faciles à utiliser, impossibles à oublier et à l’épreuve des tentatives d’hameçonnage. Elles constituent l’une des méthodes d’authentification les plus sécurisées.

### Où sont sauvegardées les clés d’accès?

Les clés d’accès sont souvent sauvegardées au sein de votre gestionnaire de mots de passe, ce qui vous permet de vous connecter sur d’autres appareils. Parfois, les clés d’accès sont directement sauvegardées sur votre appareil.

### Comment configurer une clé d’accès?

Durant le processus de création de votre identifiant ConnexionCanada, il vous sera demandé de configurer la vérification en deux étapes. La configuration d’une clé d’accès figure parmi les options disponibles. Suivez les instructions pour configurer votre clé d’accès.

Si vous décidez ultérieurement que vous souhaitez ajouter une clé d’accès à votre compte, vous pourrez le faire dans les paramètres de votre identifiant.

## Vérification par téléphone

En guise de seconde étape, vous pouvez recevoir des codes de vérification à usage unique sur votre téléphone. Vous pouvez recevoir vos codes par message texte (SMS) ou par appel vocal. Vous trouverez plus de renseignements sur ces méthodes d’envoi ci-dessous.

### Message texte

**Éléments nécessaires :** Un appareil mobile pouvant recevoir les messages texte (SMS).

Si vous utilisez les messages texte/SMS (service d’envoi de messages courts) comme méthode de vérification, un code à six chiffres à usage unique est envoyé à votre numéro de téléphone par le biais d’un message texte. Vous entrez ce code sur ConnexionCanada pour accéder à votre compte. Chaque code est temporaire. Vous aurez besoin d’un nouveau code à chaque fois que vous souhaiterez vous connecter.

Pour utiliser cette méthode, vous avez besoin d’un téléphone mobile fonctionnel connecté à un réseau cellulaire et offrant la possibilité de recevoir des messages texte lorsque vous souhaitez vous connecter. Si vous vous trouvez à l’étranger, par exemple, il est possible que vous ne puissiez pas recevoir de messages texte. Cette méthode peut également engendrer des frais si chaque message texte vous est facturé ou si le nombre de messages texte que vous pouvez recevoir est limité.

### Appel téléphonique

**Éléments nécessaires :** Un téléphone fixe **ou** mobile pouvant recevoir des appels téléphoniques.

Si vous choisissez cette option, vous recevez un appel automatisé dictant un code unique à six chiffres, que vous entrez ensuite dans ConnexionCanada pour accéder à votre compte. Chaque code est temporaire. Vous aurez besoin d’un nouveau code chaque fois que vous souhaiterez vous connecter.

Cette méthode peut être utile si vous n’avez pas de téléphone mobile ou si vous ne pouvez pas recevoir de messages texte (SMS).
